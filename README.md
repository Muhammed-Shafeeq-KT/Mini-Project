⚽ FIFA 21 Player Analysis Dashboard – Power BI
This project presents an interactive Power BI dashboard built on the FIFA 21 player dataset, designed to explore, analyze, and visualize player performance data across multiple dimensions. Whether you're a football enthusiast, data analyst, or just honing your Power BI skills, this dashboard showcases how raw data can be turned into actionable insights and compelling stories.

🎯 Objective
To analyze player attributes from the FIFA 21 dataset and create visual narratives that reveal key patterns in player performance, club strategies, and national team strengths.

🧩 Dataset
- Scope: 18,000+ players, with attributes such as overall rating, potential, age, nationality, club, skill metrics (pace, dribbling, shooting, etc.), and more.

📊 Dashboard Features
- Dynamic Filtering: Slice data by nationality, club, position, or age group.
- Top Performer Panels: Visualize top-rated players per position or league.
- Attribute Comparison: Radar charts to contrast skill profiles between players.
- Distribution Analysis: Histograms and scatter plots to show attribute trends and outliers.
- KPI Highlights: Average ratings, median age, and potential distribution.
  
🔍 Key Insight
Midfielders exhibit the widest attribute variance, with high dribbling and passing in European leagues but lower physical and defensive stats in South American clubs—revealing potential role specialization and scouting differences by region.

🚀 Use Cases
- Sports analytics and reporting
- Game data visualization portfolio
- Power BI dashboard design practice
- Exploration of global player development trends
