# FIFA 21 Player Analysis Dashboard – Power BI

An interactive Power BI dashboard built using the FIFA 21 player dataset to explore, analyze, and visualize player performance across multiple dimensions.

This project demonstrates how raw sports data can be transformed into meaningful insights and clear visual narratives.

---

## Objective

Analyze player attributes from the FIFA 21 dataset and uncover patterns in:

- Player performance  
- Club strategies  
- National team strengths  

---

## Dataset

- Size: 18,000+ players  

- Attributes include:  
  - Overall rating  
  - Potential  
  - Age  
  - Nationality  
  - Club  
  - Skill metrics (pace, dribbling, shooting, etc.)  

---

## Dashboard Features

### Dynamic Filtering  
Slice data by nationality, club, position, or age group  

### Top Performer Panels  
Identify top-rated players by position or league  

### Attribute Comparison  
Radar charts to compare player skill profiles  

### Distribution Analysis  
Histograms and scatter plots to highlight trends and outliers  

### KPI Highlights  
- Average ratings  
- Median age  
- Potential distribution  

---

## Key Insight

Midfielders show the highest variation in attributes:

- European leagues have higher dribbling and passing metrics  
- South American clubs show relatively lower physical and defensive stats  

This suggests differences in player roles, tactical styles, and regional scouting approaches.
